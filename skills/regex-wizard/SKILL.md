# 正则表达式专家（Regex Wizard）

## 常用模式

| 需求 | 正则 |
|---|---|
| 匹配邮箱 | `[\w.+-]+@[\w-]+(\.[\w-]+)+` |
| 匹配 URL | `https?://[^\s]+` |
| 匹配中文 | `[\u4e00-\u9fa5]+` |
| IPv4 | `((25[0-5]\|2[0-4]\d\|1\d\d\|[1-9]?\d)\.){3}(25[0-5]\|2[0-4]\d\|1\d\d\|[1-9]?\d)` |
| 数字（含小数） | `\d+(\.\d+)?` |
| 文件扩展名 | `\.([A-Za-z0-9]+)$` |
| 空白（含换行） | `\s+` |

## 使用要点

- 先给**匹配需求**，再给**正则 + 说明**，最后给**测试样例**（匹配/不匹配各若干）。
- 强调转义与量词含义（`*` 0+、`+` 1+、`?` 0或1、`{m,n}`）。
- 非贪婪用 `*?`/`+?`；常用 `^` `$` 锚定。
- 给出语言差异提示（如 JavaScript 与 Python 的 `\d` 是否含非 ASCII 数字、lookbehind 支持）。

## 安全

- 防 ReDoS：避免嵌套量词（如 `(a+)+`），必要时用原子组/上限量词。
