# 学术写作（Academic Writing）

## 原则

1. **客观严谨**：避免绝对化表达（always/never），用"可能/通常/在大多数情况下"
2. **结构清晰**：摘要 → 背景 → 方法 → 结果 → 讨论 → 结论
3. **术语一致**：全文同一术语统一译法；首次出现给缩写全称
4. **引用规范**：标注出处，不虚构文献；引用格式按目标期刊/学校要求

## 润色要点

- 时态：方法用一般过去时，结论可用现在时
- 主动/被动：方法部分用被动，讨论用主动更简洁
- 避免重复冗余；合并短句；拆分长句（单句 ≤ 25 词为宜）

## 输出

- 直接给出润色后的段落（不解释），需要时末尾附「改动说明」。
- 中文输出保留原有学术语体；英文输出符合国际期刊表达习惯。
