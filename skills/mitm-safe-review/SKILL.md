# 安全审查（Security Review）

## 快速识别清单

### 依赖
- 锁定版本、避免 `*` / `latest`；检查已知 CVE（用 npm audit / pip-audit / osv 等）
- 禁用 `--ignore-scripts` 未审的第三方安装脚本

### 密钥与机密
- 检索仓库中的 `.env` 硬编码、`api_key`/`token`/`password`/`secret` 明文
- 确认 `.gitignore` 覆盖 `.env`、证书、私钥；历史提交是否泄密（需轮换）

### 输入与注入
- 对外输入是否校验/转义（SQL/命令/路径/模板注入）
- 文件上传类型/大小限制；路径穿越校验

### 权限
- 最小权限原则；越权访问（水平/垂直）；默认口令/弱口令
- 敏感接口是否需要鉴权与限流

### 传输与存储
- 强制 HTTPS；敏感字段加密/脱敏；日志不打印明文机密

## 输出

按「风险等级 + 位置 + 理由 + 修复建议」输出；无法确认的标「需人工确认」。
