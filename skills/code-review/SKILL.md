# 代码审查（Code Review）

按以下清单逐项审查，输出结构化报告（严重度 + 位置 + 建议）。

## 检查维度

1. **健壮性**：空值/边界处理、异常捕获、资源释放、并发热点
2. **安全**：输入校验、路径穿越、注入、敏感信息硬编码
3. **可维护性**：命名、重复代码、可读性、注释与文档
4. **性能**：不必要递归/循环、冗余 IO、算法复杂度
5. **规范**：命名约定、错误处理一致性、日志

## 输出格式

```
### P0（必须修）
- 位置 + 问题 + 原因 + 修复建议

### P1（建议修）
- ...

### P2（可选）
- ...
```

## 说明

- 只读审查，不改代码；给出可执行的修复建议。
- 引用具体文件行号，便于定位。
- 未知/不确定的点标注「需确认」，不臆断。
