# README 生成器

## 结构（按需精简）

```markdown
# 项目名
> 一句话介绍（是什么、解决什么问题）

## 功能特性
- ...

## 快速开始 / 安装
// 前置依赖、安装命令、验证

## 使用说明
// 基本用法 + 示例 + 常见参数

## 配置 / 环境变量
// 可选

## 截图 / 演示
// 可选

## 项目结构
// 可选

## 常见问题（FAQ）
// 可选，解决高频问题

## 贡献
// 如何提 issue / PR、代码规范

## 许可
// License
```

## 原则

- **从用户视角写**，站在第一次使用的开发者角度。
- 命令/路径用代码块；关键步骤给示例输出。
- 表格化选项参数更易读。
- 不编造功能/版本号/截图；不确定处标「待补充」。
