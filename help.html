📋 一、项目介绍

DSH-Desktop 是 DeepSeek Harness 的桌面客户端，为用户提供便捷的 AI 交互体验。

核心特点：

  • 🚀 一键安装 - 无需复杂配置，下载即用
  • 🔄 自动更新 - 支持远程下发更新，保持最新版本
  • 💡 内置提示词库 - 提供丰富的提示词模板，提升使用效率
  • 🎨 桌面宠物 - 可爱的桌面伴侣，支持互动
  • 🔧 插件市场 - 连接官方社区，扩展功能

DSH-Desktop 基于 Electron 构建，支持 Windows 系统，为您提供稳定、高效的 AI 交互环境。

⚠️ 二、下载更新失败？请关闭科学上网

DSH-Desktop 的下载和更新服务依赖 GitHub CDN。如果您在使用过程中遇到下载失败或更新卡顿的问题，可能是因为您的网络环境受到了代理工具（科学上网）的影响。

解决方案：

1. 请暂时关闭您的代理软件（如 Clash、V2Ray、Shadowsocks 等）

2. 关闭 VPN 连接

3. 重新尝试下载或更新

关闭代理后，DSH-Desktop 可以直接连接到 GitHub 服务器，获得更快的下载速度和更稳定的连接。
