01📋 项目介绍

DSH-Desktop 是 DeepSeek Harness 的桌面客户端，为你提供便捷、稳定的 AI 交互体验，基于 Electron 构建，支持 Windows 系统。

核心特点：

  • 一键安装 — 无需复杂配置，下载即用，自带运行环境
  • 自动更新 — 支持远程下发更新，始终保持在最新版本
  • 内置提示词库 — 丰富模板即取即用，提升使用效率
  • 桌面宠物 — 可爱的桌面伴侣，支持互动与气泡提示
  • 插件市场 — 连接官方社区，按需扩展功能
  • 全局记忆 — 图形化记忆编辑，DSH 自动读取

无论是日常问答、内容创作，还是代码辅助、工作流自动化，DSH-Desktop 都能为你提供稳定的 DeepSeek AI 能力。

03🧭 使用指南

快速了解常用功能，开箱即用。

🐳 桌面宠物

桌面鲸鱼伴侣，可拖拽到任意位置。悬停/点击会切换表情、弹出气泡提示，右键可隐藏或切换工具箱形态。

📝 提示词库

内置 200+ 精选提示词模板，支持搜索、复制与一键注入输入框；「我的提示词」可自建并持久化保存。

📥 拖文件入工作区

把文件拖进窗口，自动复制到当前 DSH 工作区并注入提示词；纯图片（PNG/JPG/WebP/GIF）直接放行给 DSH 显示缩略图附件。

🧠 全局记忆

图形化编辑 ~/.dsh/AGENTS.md 与各角色记忆文件，让 DSH 记住你的称呼、项目背景与常用约定，无需手动发送。

🔌 插件市场

连接官方社区，分类浏览、搜索、一键复制安装命令，按需扩展能力。

💾 数据备份

一键备份 DSH 用户数据（工作区/会话/全局记忆/我的提示词/设置），更换机器或出问题时快速恢复。

04❓ 常见问题

下载更新失败？

多为本地代理环境（科学上网）干扰。关闭代理后重试；仍失败可用「手动下载安装包」或百度网盘备用渠道。

提示词或插件描述是乱码？

旧版本已修复中文乱码问题。若仍有乱码，请先更新到最新版确认网络拉取正常。

我的提示词会丢失吗？

不会。「我的提示词」持久化保存在本地，重启不丢，并通过「数据备份」随包备份，恢复可还原。

想手动升级 DSH？

启动时检测到 DSH 新版会弹窗提示「立即升级」；也可在「检查更新」窗口查看并一键升级。

找不到答案？

加入上方 QQ 群，或到 GitHub 提 issue，我们会尽快响应。

05⚠️ 下载 / 更新失败？请关闭科学上网

DSH-Desktop 的下载与更新依赖 GitHub CDN。若下载失败或更新卡顿，多为本地代理环境所致。

💡

解决方案：

1. 暂时关闭代理软件（Clash、V2Ray、Shadowsocks 等）

2. 关闭 VPN 连接

3. 重新尝试下载或更新

关闭代理后，可直连 GitHub 服务器，获得更快的速度与更稳定的连接。
