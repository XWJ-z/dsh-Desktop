01 项目介绍

DSH-Desktop 是 DeepSeek Harness 的客户端，为你提供便捷、稳定的 AI 交互体验。同一套 DSH 能力，两种载体：Windows 桌面版与飞牛 OS 原生应用。点击下方切换，查看各平台详细介绍。

Windows 桌面版基于 Electron 打磨，把 DeepSeek Harness 收进一个精致、随时能打开的桌面窗口。下载安装包、双击运行即用，无需任何复杂配置，自带运行环境。

无论是日常问答、内容创作，还是代码辅助、工作流自动化，它都能为你提供稳定的 DeepSeek AI 能力；还可拉起桌面鲸鱼宠物陪伴，把 AI 融入你的每一次敲击。

⇩ 下载 Windows 安装包

飞牛 OS 原生应用把同一套 DeepSeek Harness 跑在你的 NAS 上。安装 .fpk 应用包后，网关把 DSH Web 界面映射到飞牛的应用入口（/app/dsh），应用中心安装即用、开箱即用。

运行时由应用首次启动时自动安装到数据目录，与 Windows 版「适配 DSH 套壳、按版本拉取」同机制。适合把 AI 能力常驻在私有云，随时从局域网访问。

平台要求飞牛 OS (fnOS) v1.1.3100+ · 全平台
运行依赖nodejs_v22（安装时自动关联）
安装包dsh-0.2.5.fpk · 约 0.3MB
应用入口应用中心 → 打开 dsh 即用

02 使用指南

快速了解常用功能，开箱即用。

🖥 桌面鲸鱼宠物

桌面鲸鱼伴侣，可拖拽到任意位置。悬停/点击会切换表情、弹出气泡提示，右键可隐藏或切换工具箱形态——在日常使用中始终陪伴，随时唤起。

✎ 提示词库

内置 200+ 精选提示词模板，支持搜索、复制与一键注入输入框；「我的提示词」可自建并持久化保存。

⇪ 拖文件入工作区

把文件拖进窗口，自动复制到当前 DSH 工作区并注入提示词；纯图片（PNG/JPG/WebP/GIF）直接放行显示缩略图附件。

◎ 全局记忆

图形化编辑 AGENTS.md 与各角色记忆文件，让 DSH 记住你的称呼、项目背景与常用约定，无需手动发送。

⌘ 插件库

连接官方社区，分类浏览、搜索、一键复制安装命令，按需扩展能力。

⛁ 数据备份

一键备份 DSH 用户数据（工作区/会话/全局记忆/我的提示词/设置），更换机器或出问题时快速恢复。

04 下载 / 更新失败？请关闭科学上网

DSH-Desktop 的下载与更新依赖 GitHub CDN。若下载失败或更新卡顿，多为本地代理环境所致。

◈

解决方案：

1. 暂时关闭代理软件（Clash、V2Ray、Shadowsocks 等）
2. 关闭 VPN 连接
3. 重新尝试下载或更新

关闭代理后，可直连 GitHub 服务器，获得更快的速度与更稳定的连接。
