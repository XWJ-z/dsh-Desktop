## P0（必须，先做）

### 任务1：修复启动页 logo 不显示（H1）

**现象：** 启动界面 logo 图片不显示
**根因：** `app/renderer/loading.html` 的 CSP `default-src 'self'` 在 file:// 协议下无法匹配本地图片，`../assets/icon.png` 被拦截
**修复（推荐方案B）：** logo 改为内联 base64
```html
<!-- 将 <img class="logo" src="../assets/icon.png"> 替换为 -->
<img class="logo" src="data:image/png;base64,<icon.png的base64内容>" />
```
生成 base64：`node -e "console.log(require('fs').readFileSync('assets/icon.png').toString('base64'))"`
或方案A：CSP 增加 `img-src 'self' file: data:`
**验证：** 启动应用，logo 正常显示；F12 控制台无 CSP 报错

---

### 任务2：修复主窗口尺寸 + 加载空白（H2）

**现象：** 看不到启动过程；主窗口实际是 1280×820（loading 窗口尺寸）
**根因：** `createLoadingWindow()` 创建的窗口在服务就绪后被 `loadURL` 复用为主窗口（main.js:592），`createMainWindow()`（1440×900）正常流程永远不执行
**修复：**
1. 服务就绪后：关闭 loading 窗口 → `createMainWindow()` 新建主窗口（推荐，职责清晰）；或复用窗口时 `win.setSize(1440, 900)`
2. 主窗口加载 GUI 期间显示"正在加载界面…"覆盖层，`did-finish-load` 后移除（解决黑屏期无反馈）
**验证：** 二次启动（无下载）时窗口切换流畅，主窗口 1440×900，加载期有过渡提示

### 任务3：修复选择工作区失败（H3）🔴 重点

**现象：** 点击选择工作区文件夹报错：
`directory picker failed: win32 folder dialog worker exited before reporting a result`
**根因：** DSH 的原生目录选择器（koffi COM 绑定）等原生模块按 **Node ABI** 编译，打包模式下壳用 `ELECTRON_RUN_AS_NODE=1`（Electron-as-Node）运行 DSH，**ABI 不兼容**导致目录选择 worker 崩溃。同类隐患：sharp 图片处理、node-pty 终端等
**修复（推荐）：内置真实 Node 运行时**
1. 下载 Node 24 LTS（Windows x64）官方二进制，打包进 `resources/node/node.exe`
2. 修改 `resolveRunner()`（main.js:276-285）：打包模式优先使用内置 `resources/node/node.exe`，`ELECTRON_RUN_AS_NODE` 降为后备
3. 顺带可移除 `--expose-internals` hack（main.js:360，真实 Node 下不再需要）
4. electron-builder.yml `files` 需包含 `resources/node/**`（注意排除规则）
**参考：** 同款项目已验证此方案——`qyqy-1109/deepseek-harness-desktop` v0.1.2（内置真实 Node 24，koffi/sharp/node-pty 全部修复）
**替代方案（治标）：** 目录选择 worker 以 `ELECTRON_RUN_AS_NODE` 子进程模式启动（参考 `whitelonng/dshcode` rc.6），只修 picker，其他原生模块隐患仍在
**验证：** 打包后运行，选择工作区 → 文件夹对话框正常打开；测试 DSH 中图片处理/终端功能正常

## P1（建议做）

### 任务4：子进程残留清理（M1）

**问题：** `ensureDshRuntime` 的 npm 安装子进程是局部变量（main.js:216），app 退出时不被 kill（`stopServer` 只处理 `serverChild`），Windows 下可能残留 npm/node 进程
**修复：** 全局登记所有子进程（npm install + serverChild），`before-quit` 统一 kill；启动失败路径（main.js:596-602）同样清理

### 任务5：启动阶段进度 UI

**目的：** 首次启动 npm 下载几分钟，用户看不到进度
**方案：** loading 页加阶段指示器，主进程通过 IPC 推送阶段：
```
① 检查 DSH 运行时 → ② 下载/安装（百分比）→ ③ 启动服务 → ④ 就绪
```
npm 进度：`npm install --json` 解析 progress，或轮询 dshenv 目录体积估算
