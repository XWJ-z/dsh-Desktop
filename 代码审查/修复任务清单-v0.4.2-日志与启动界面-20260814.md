## 任务C：修复日志时间晚 8 小时（P0，约10分钟）

**现象：** 日志时间比系统时间晚 8 小时（UTC vs 北京时间）

**根因：** `appendLog` 用 `new Date().toISOString()`（main.js:98）返回 UTC 时间；`logPath()` 文件名日期（main.js:82）同为 UTC，深夜运行时日志会归到前一天

**修复：**

1. 新增两个本地时间函数（放在 `logPath()` 之前）：
```js
/** 本地时间戳（yyyy-MM-dd HH:mm:ss），解决 UTC 与北京时间差 8 小时 */
function localTimestamp() {
  const d = new Date();
  const p = (n) => String(n).padStart(2, '0');
  return `${d.getFullYear()}-${p(d.getMonth() + 1)}-${p(d.getDate())} ${p(d.getHours())}:${p(d.getMinutes())}:${p(d.getSeconds())}`;
}
/** 本地日期（yyyy-MM-dd），用于日志文件名（避免深夜日志归到前一天） */
function localDate() {
  const d = new Date();
  const p = (n) => String(n).padStart(2, '0');
  return `${d.getFullYear()}-${p(d.getMonth() + 1)}-${p(d.getDate())}`;
}
```

2. 替换两处：
```js
// logPath() 内（原 main.js:82）
const stamp = new Date().toISOString().slice(0, 10);
// 改为：
const stamp = localDate();

// appendLog() 内（原 main.js:98）
const line = `[${new Date().toISOString()}] [${level}] ${message}`;
// 改为：
const line = `[${localTimestamp()}] [${level}] ${message}`;
```

**验证：** 启动应用，日志时间与系统时间一致（±1秒）；深夜（00:00后）启动日志归到当天文件名。

### D2. 下载进度可视化（核心体验）

**目标：** 阶段②（下载/安装）显示进度，用户看到"在干活"。

**方案（轻量推荐）：目录体积轮询**
- npm install 期间，主进程每 2 秒统计 `dshRuntimeDir()` 目录体积（MB），经 IPC 推送
- 阶段②旁显示："已下载 23.4 MB…"（无总量估算时用不定进度条动画 + 数字）

**改动：**

1. `main.js` 新增轮询（在 ensureDshRuntime 安装分支启动，exit 后停止）：
```js
/** 统计目录体积（MB，一位小数） */
function dirSizeMB(dir) {
  try {
    let total = 0;
    const walk = (d) => {
      for (const e of fs.readdirSync(d, { withFileTypes: true })) {
        const p = path.join(d, e.name);
        if (e.isDirectory()) walk(p);
        else total += fs.statSync(p).size;
      }
    };
    walk(dir);
    return (total / 1024 / 1024).toFixed(1);
  } catch { return '0.0'; }
}

// ensureDshRuntime 的安装分支中，spawn 后启动：
const progressTimer = setInterval(() => {
  pushProgress({ mb: dirSizeMB(dshRuntimeDir()) });
}, 2000);
// child exit 时 clearInterval(progressTimer);
```
> 推送通道可复用 `pushStage` 机制扩展：`pushProgress` 发 `dsh:progress` 事件，或直接在阶段消息里带字段。保持 preload 最小暴露原则。

2. `loading.html` 阶段②元素加进度文本：
```html
<div class="stage" data-stage="install">② 下载 / 安装 <span id="dl-progress"></span></div>
```

3. `loading.js` 监听进度并更新 `#dl-progress`。

**验证：** 首次启动（清空 dshenv）阶段②显示"已下载 xx.x MB…"持续增长，安装完成消失。
